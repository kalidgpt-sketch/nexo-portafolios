NEXO. - WEB DE PORTAFOLIOS (versión sin carpetas, para subir desde el móvil)

ARCHIVOS (6): index.html (galería principal), marta.html, lucia.html, daniel.html, pablo.html, sara.html

SUBIR A GITHUB (repositorio nexo-portafolios)
1. Descomprime este zip en la app Archivos del iPhone (toca el zip una vez).
2. En el repositorio: Add file > Upload files > elige los 6 archivos .html (todos a la vez) > Commit changes.
3. Borra "nexo-web (1).zip" del repositorio (opcional).
4. Settings > Pages: Branch main, carpeta / (root). El campo "Custom domain" déjalo VACÍO.
5. Abre https://kalidgpt-sketch.github.io/nexo-portafolios/ (tarda 1-2 minutos).
